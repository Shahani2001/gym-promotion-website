# Fitness Gym Promotional Website

## Project Name
New Local Fitness Gym Promotion Site

## Tech Stack
- HTML5
- CSS3 (Flexbox/Grid, Animations, Responsive)
- Vanilla JavaScript (Form validation, Dark mode, Smooth scroll)

## Setup Instructions
1. Download/copy branding assets (logo.png, gym-hero.jpg, trainer1-3.jpg etc.) to `images/` folder.
2. Open `index.html` in any modern browser.
3. Test responsive: Chrome DevTools > Toggle device toolbar.

## Features
- Fully responsive (mobile/desktop)
- Hero section with CTA
- About, Services (classes/plans), Trainers
- Contact form: validation (name, email, message), success feedback
- Bonus: Dark mode toggle, fade-in animations, hover effects

## Live Demo
Open index.html or run local server:
```
cd gym-promotion-website
python -m http.server 8000
```
Visit http://localhost:8000
